Cyclio Privacy Policy

Effective date: 01.10.2026

Publisher: Matej Zupančič, Slovenia

Privacy contact: cyclio.app@gmail.com

Overview

Cyclio is a local cycling and fitness application. It uses precise device location to show cycling measurements and, when the user starts recording, to create a ride record. The release described by this policy has no account system, no advertising SDK, no analytics SDK, and no live-location sharing feature.

Information processed on the device

The app may process precise GPS coordinates, timestamps, location accuracy, speed, distance, moving time, elevation, ascent, gradient, recorded route points, ride statistics and locally calculated best efforts, optional ride names and notes, favourites, completed laps, ride goals, local-alert preferences, Trash state, locally saved GPX privacy zones, bicycle names, odometers, maintenance reminders, maintenance notes, app settings, and unfinished-ride recovery data.

This information is stored in the app's private storage on the device until the user deletes it, clears app data, or uninstalls the app.

Android automatic backup

Cyclio disables Android automatic cloud backup. It also requests, through explicit Android rules, that app-private data be excluded from Android-managed backup and device transfer. Some device manufacturers can implement migration differently. Users may instead create a manual Cyclio backup through the app.

Maps and external network requests

When a user opens a saved-route map, the app may request map image tiles for the viewed area from the configured map provider. A map provider can receive the requested tile coordinates, IP address, user-agent information, and request time. The default map data attribution is © OpenStreetMap contributors. See OpenStreetMap copyright and licence information.

The recorded route remains stored locally. The route line can be displayed without a map underlay.

User-directed exports

The user may deliberately save or share GPX route files, locally generated ride-summary images, and Cyclio backup files. GPX files and backups can contain precise historical locations, timestamps, ride information, bicycle data, maintenance information, and settings. Before GPX export, the app can locally trim the start or finish, omit timestamps or elevation, simplify the route, and hide route points inside privacy zones stored on the device. Ride-summary images omit the route by default unless the user chooses to include an abstract route trace. Manual Cyclio backups can optionally be password-encrypted. GPX files and ride-summary images are not password-encrypted. After the user selects a destination or another app, the recipient's privacy practices apply.

Permissions

Precise location is used to calculate speed, distance, route, elevation, ascent, and gradient. A foreground location service is used only during an explicitly recorded ride so tracking can continue during ordinary interruptions. Notification permission is used to show the ongoing ride notification. Vibration is used only for enabled local alerts. Internet access is used for online map tiles.

Retention and deletion

Users can rename rides, add notes, mark favourites, move rides to Trash, restore them, or permanently delete them. Trashed rides are excluded from totals and are automatically purged after 30 days unless restored or permanently deleted earlier. Users can also delete bicycles and maintenance entries through the app. The “Delete all Cyclio data” action removes completed rides, routes, unfinished-ride data, bicycles, maintenance records, settings, cached map tiles, and temporary export files from the app's storage. Files previously exported outside the app must be deleted by the user from their chosen destination.

Children

Cyclio is not designed as a child-directed service and does not knowingly create accounts or collect children's information on a developer-operated server.

Security and limitations

The app uses Android private storage for local data. No security method can guarantee protection against a compromised device. Manual Cyclio backups can optionally be password-encrypted. GPX files and route-containing summary images are not password-encrypted and should be handled carefully because they may reveal home, work, or other sensitive locations. GPX trimming and privacy zones can reduce exposure but do not guarantee anonymity.

Changes

This policy may be updated when app behaviour or legal requirements change. The effective date above will be updated.
